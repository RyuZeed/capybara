# 👑 Ritod Hub Lite - Capybaras vs Plants

Script otomatisasi serbaguna (*modular edition*) untuk game Roblox **Capybaras vs Plants**.

---

### 🚀 Cara Menjalankan Script di Roblox Executor

Salin dan tempel **1 baris perintah di bawah ini** ke dalam Executor Anda (Delta, Solara, Wave, Xeno, dll):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/RyuZeed/capybara/main/main.lua"))()
```
